# Library Management System CLI (Thursday Mini-Project)

An interactive, strictly-typed command-line application built with TypeScript to handle book collections dynamically in memory.

## Key Features Applied
- **Strict Data Structuring:** Using TypeScript `Interface` to control object shapes.
- **Advanced Searching:** Applying string filtering methods for quick resource identification.
- **State Modification:** Tracking `isBorrowed` parameters within typed object arrays.
- **Input Sanitation:** Trimming variables dynamically across recursive switch-case statements.

## How to Run
1. Compile the project files:
   ```bash
   tsc
   ```
2. Launch the application:
   ```bash
   node library.js
   ```
