# 🎓 Student Management CLI App

A simple and interactive command-line application built with modern JavaScript (ES6+) to manage student records in memory.

## 🛠️ Features
- **Add Student:** Register a student with ID, Name, DOB, Email, and Department.
- **List All Students:** View all registered students in a formatted list.
- **Search Student:** Find a specific student instantly using their unique ID.
- **Update Student:** Modify student records safely using the **Spread Operator**.
- **Delete Student:** Remove student records using the array **Filter method**.

## 🚀 Technologies Used
- JavaScript (ES6+)
- Node.js (Built-in `readline` module)
- Git & GitHub
