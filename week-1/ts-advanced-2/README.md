# 📅 Arrays, Generics & Best Practices (Friday Task)

The final project of Week 1 focuses on writing advanced, reusable, and type-safe TypeScript code using Generics and proper structural conventions.

## 🛠️ Concepts Mastered & Applied
- **TypeScript Generics (`<T>`):** Building a dynamic, multi-purpose `DataStorage` class capable of handling any data type safely.
- **Reusable Utility Functions:** Creating a generic `getLastItem` helper function to safely manipulate arrays.
- **Array Manipulation & Type Safety:** Safeguarding array iteration sequences while avoiding implicit runtime bugs.
- **Coding Conventions:** Enforcing strict structural styling rules (`camelCase` for variable declarations and `PascalCase` for Interfaces/Classes).

## Execution Guide
1. Compile the advanced type properties:
   ```bash
   tsc
   ```
2. Launch the finalized application module:
   ```bash
   node advanced.js
   ```
