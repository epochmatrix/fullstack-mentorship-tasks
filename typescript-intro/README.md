# 📘 Introduction to TypeScript (Wednesday Task)

An introductory project to master the fundamentals of TypeScript, static typing, and environmental configurations.

## 🛠️ Concepts Learned & Applied
- **Primitive Types:** Explicitly and implicitly declaring `string`, `number`, and `boolean` types.
- **Type Aliases:** Creating custom data models (`StudentProfile`) to handle structured data cleanly.
- **Union Types:** Utilizing `StudentID = number | string` for flexible type handling.
- **TypeScript Compiler (tsc):** Configuring and initializing `tsconfig.json` to manage project compilation settings.
- **Error Handling:** Understanding and troubleshooting compiler feedback and script policies.

## 🚀 How to Run the Project
1. Compile TypeScript to JavaScript:
   ```bash
   tsc
   ```
2. Execute the compiled JavaScript file:
   ```bash
   node index.js
   ```
