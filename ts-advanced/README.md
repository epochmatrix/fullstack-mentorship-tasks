# TypeScript Functions, Objects & Interfaces 

An advanced project focusing on data structuring and typing functions using TypeScript Interfaces and Nested Objects.

## Concepts Applied
- **TypeScript Interfaces:** Defining strict shapes for objects (`Address`, `Course`, `MentorshipStudent`).
- **Nested Objects:** Embedding the `Address` object structure inside the main student profile.
- **Arrays of Objects:** Managing an array of objects for tracking enrolled courses.
- **Typed Functions:** Implementing precise input parameter types and explicit return values.
- **Default & Optional Parameters:** Safeguarding application flow with fallback configurations.

## Execution Guide
1. Compile the project configurations:
   ```bash
   tsc
   ```
2. Run the compiled application:
   ```bash
   node app.js
   ```
